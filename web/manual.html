01三分钟上手

第一次用，照着这五步做就行。

  1. 双击文件夹里的 start.command

    会弹出一个终端窗口，等几秒，浏览器会自动打开「汉字小岛」。

  2. 看到首页后，点「开始学习 · N 个字」

    N 是这次要过的字数，包含复习和新字。

  3. 陪孩子看新字卡，点「开始认字」

    每个新字会先出现一张大字卡，听完读音、读完组词，再进入认字题。

  4. 做完题，看星星，点「回小岛」

    90% 以上三颗星，70% 以上两颗星，其余一颗星。星星只用来鼓励，不排名。

  5. 想停止时，双击 stop.command

    也可以直接合上电脑。下次再双击 start.command 就能继续。

第一次启动可能慢一点。 应用需要 Python 3，并会自动安装依赖，这一步要联网；装好之后就可以完全离线使用。

02启动和退出

不需要懂技术，双击两个文件就够了。

启动

  • 双击 start.command，等浏览器自动打开。
  • 如果 macOS 提示「无法打开」，在文件上右键 → 打开，再点一次「打开」。
  • 启动脚本跑完后，终端窗口可以关掉，服务在后台继续运行。
  • 默认地址是 http://127.0.0.1:8765。端口被别的程序占用时，会自动换到 8766–8775，以终端窗口显示的地址为准。
  • 建议把页面收藏到浏览器书签，或者固定成标签页，下次直接点开。

退出

  • 双击 stop.command。它只会停止「汉字小岛」，不会影响别的程序。
  • 直接关机、合盖也可以。学习记录会保存在本机，不会丢。
  • 不建议同时开两个窗口学习，进度以最后一次答题为准。
需要联网吗？ 只有第一次安装依赖需要联网。之后学字、听读音、看短文都在这台电脑上完成，不联网也能用。

03四个底部页面

底部四个按钮给孩子用；家长看板入口收在今日页，避免孩子误触。

页面用来做什么什么时候用
今日 每天的学习入口、复习和新字队列、闯关地图 每天开始学习时
字卡册 按册和单元翻所有字卡；字族、多音字；打印字卡 复习旧字、睡前翻一翻、打印贴墙
读一读 30 篇短文和儿歌（上册 17 / 下册 13）；可按册筛选，点字听音、点 ▶ 听整句 学完一个单元后，做朗读练习
认字 幼儿识字 1300 整体过一遍、每日艾宾浩斯复习、打印不会的字 想快速摸底、集中攻不会的字时

今日页也有一张认字卡。它和「今天的任务」并存，显示整体过字进度和今天到期的认字复习。

家长看板不在底部。在今日页顶部数字下面，点「家长看板 · 设置与学习记录」进入；也可以直接打开 #/parent。这样孩子不容易误触设置和清空按钮。

右上角还有一个「声 / 静」按钮，可以随时关掉或打开声音。

04每天怎么带（10–12 分钟）

短而稳定，比一次学很多更有效。

推荐流程

  1. 固定一个时间

    放学后、晚饭前或睡前都可以。每天同一时间，孩子更容易进入状态。

  2. 先看「复习 N / 新字 M」

    应用会先安排到期的旧字，再安排新字。复习最多 15 个，整组最多 20 题。

  3. 有艾宾浩斯复习时，先做哪边都可以

    今日页的「艾宾浩斯认字」卡会显示今天有多少字到期。时间紧时先做认字复习；时间够再学新字。两个队列分开记录，不会互相覆盖。

  4. 复习题：让孩子自己点

    答错没关系，应用会显示正确答案、读音和意思，跟着读一遍就好。

  5. 新字卡：听一遍、读一遍

    先听自动连读（字音 → 组词 → 组词），再让孩子指读大字，最后点「开始认字」。

  6. 认字题：三种题型轮换

    听音选字、句子填空、看拼音选字。每题四个选项，不会默认选中。

  7. 结算：看星星，决定要不要再来一组

    状态好就点「再学一组」；累了就点「回小岛」，明天继续。

家长坐在旁边做什么

  • 当读题人，不当抢答人。孩子点得慢一点没关系，等他自己选。
  • 可以问：「这个字读什么？」「你听到的是哪个字？」「这句话里缺了谁？」
  • 答错时不说「怎么又错了」，可以说：「我们看看它到底读什么。」
  • 孩子连续学 12 分钟，会弹出「让小眼睛休息一下」，跟着数 20 下再继续。
  • 孩子明显累了、坐不住了，就点左上角 × 结束。已经答过的题会保存。
一天学多少合适？ 默认每天 5 个新字，建议 3–6 个。新字是按整课安排的，可能比设置多 1–2 个， 比如第一课《天地人》会一次学完 6 个字。

05今日页

每天从这里开始。

上面三个数字

学过 / 688已经见过并答过题的不同汉字数。
待复习今天到期、需要再认一遍的字。
连续天数连续有答题记录的天数。
正确率今天答对的比例，答过题后才显示。

今天的任务卡

  • 复习 N：今天到期的旧字。
  • 新字 M：今天要学的新字。
  • 今日已答：今天已经做过的题数。
  • 还有 N 个到期：今天没排进这一组的到期字，下次会优先安排。
  • 按钮文字：当天还没答题时是「开始学习」，答过之后变成「再学一组」，后面都会显示这次要过多少个字。

艾宾浩斯认字卡

  • 第一次用：点「开始过一遍」，选幼儿识字 1300、全部课内 688、一年级上册或下册。
  • 过字时一次只出现一个大字，不显示拼音；孩子自己点「认识」或「不认识」。
  • 正在过：显示已经过多少、认识多少、不认识多少；可以随时退出，下次接着来。
  • 过完一遍：每天按记忆曲线显示到期复习；没有到期时显示「今天没有到期复习」。
  • 这张卡和「今天的任务」是两套记录：认字自评不会直接增加上面的「学过 / 688」。
  • 有自评「不认识」的字时，认字页会出现「打印不会的字」，可以生成 A4 清单。

闯关地图

  • 可以按「全部 / 一年级上册 / 一年级下册」切换。
  • 每一课显示已学 / 总数和进度条，学完的课会打 ✓。
  • 点一课，会弹出这一课的字卡；再点其中一个字，可以看详细字卡。
  • 688 是不同汉字数；702 是课程位置数。有的字在不同课文里出现，所以位置会比字数多。
  • 上册 279 + 下册 413 中有 4 个字两册都出现，所以相加是 692；按不同字去重后仍是 688。

06学新字页

先看清楚，再开始做题。

新字出现时，应用会自动连读：字音 → 第一个组词 → 第二个组词。 如果不想自动读，可以在「今日页 → 家长看板 → 学习设置」里关掉「自动播放读音」。

页面上的内容怎么用
大字和拼音让孩子先看字形，再读拼音；点拼音可以显示或隐藏。
部首 · 笔画 · 结构 · 造字法不用全讲，挑孩子能理解的說一句就好。
意思用生活里的例子解释，比背解释更有用。
字形演变日、月、山、水、火、木、田、人、口、目 这 10 个字有图，可以讲讲「以前像什么」。
组词点词可以听读音，让孩子跟着读一遍。
句子句子里这个字会高亮，让孩子在句子里认它。
记忆口诀帮助记字形，不用背，读一遍即可。
形近字提醒孩子别和哪个字弄混。

看完点「开始认字」，或者直接按 Enter。想再听一遍，点「听读音」。

建议的带法：听一遍 → 孩子指读一遍 → 挑一个组词造个句子 → 点「开始认字」。 不要在一个字上停太久，后面还会复习。

07三种认字题

换着题型练，避免只会一种。

题型题目长什么样孩子要做什么
听音选字 「听一听，点出这个字」 听读音，从四个字里点出正确的那个；可以点「再听一遍」。
句子填空 「选一个字，把句子补完整」 看句子里的括号，选出合适的字。
看拼音选字 「看拼音，点出这个字」 读拼音，从四个字里选。

答题时会发生什么

  • 进入题目时不会默认选中任何选项，孩子必须自己点。
  • 答对：出现绿色 ✓，应用会再读一遍这个字。
  • 答错：显示正确答案、读音和意思，也会再读一遍。不是批评，只是再认一次。
  • 点「下一个」继续，或者按 Enter。
  • 答错的字会降一级，按新的等级安排复习：越不熟的字，下次出现得越早。
  • 干扰项来自形近字、同课字、已学字，不会随便拿没学过的字来凑。
不要替孩子点。 答错的价值比答对更大：应用会根据对错安排下次复习时间。替点会让复习节奏失真。

08字卡册

所有字都在这里，可以随时翻、随时听、打印。

怎么找字

  • 先选册：「全部 / 一年级上册 / 一年级下册」。
  • 再选单元，下面会按课文列出字卡。
  • 字卡册顶部有「按部首认字」：常用部首直接点，全部 99 个部首用下拉框选，下面会列出这个部首的字。
  • 字卡颜色表示熟悉程度：白色是新字，金色是学习中，青色是熟悉，绿色带 ★ 是已掌握。
  • 点任意一个字，打开详细字卡。

字卡弹窗里有什么

  • 大字、拼音、部首、笔画、结构、掌握程度。
  • 意思、字形演变（10 个象形字）、组词（点词听音）、句子、记忆口诀。
  • 字族：和这个字同一部件或同一部首的字，点一下可以接着看。
  • 同部首：按部首自动归类的字，最多显示 8 个，其余会写「还有 N 个」。
  • 多音字：一个字有几种读法时出现，每个读音都能点听。
  • 学习记录：只有答过题的字才显示，避免新字弹出「0 次」。

字族和多音字面板

  • 字族：23 组精选字族（青、包、也……），加上顶部「按部首认字」的 99 组同部首分类，覆盖 610 个字。
  • 多音字：教材里标注的 8 个，加上 30 个常见补充，共 38 个。补充的读音会标「补充」。
  • 补充的多音字只收读音音频齐全的，点了不会没声音。

打印

点「打印这一页」，会按适合打印的样式输出当前单元的字卡，可以剪下来贴墙上或放进识字盒。

09读一读

把学过的字放回句子和儿歌里。

  • 共 30 篇短文和儿歌，按册和单元分组；顶部可以选「全部 / 一年级上册 / 一年级下册」，下册有 13 篇。
  • 点一篇打开，每一行是一句话。
  • 点单个字听读音；点句子右边的 ▶ 听整句（逐字连读）。
  • 多音字按句子语境读，比如「站得直」读 de，「数一数」读 shǔ，「长大」读 zhǎng。
  • 可以「显示拼音 / 隐藏拼音」。刚开始可以显示，熟悉后隐藏，练纯认字。
  • 灰色的字表示还没学过，也可以点，不影响学习记录。
  • 每篇会显示「认识 X / Y」，方便看这篇里孩子认识多少不同的字。
怎么用最好：学完一个单元后，找对应短文读一遍；或者睡前让孩子点一句， 家长跟着读一句。读错了不用打断，读完再回头点那个字听一遍。

10艾宾浩斯认字

先自评，再用答题验证；不靠一次考试定输赢。

第一次：整体过一遍

  • 点底部「认字」，再点「开始过一遍」；也可以从今日页的认字卡进入。
  • 选范围：幼儿识字 1300（推荐，含课内 664 + 拓展 636）、全部课内 688、一年级上册或下册。
  • 一次只出现一个大字，不显示拼音、不自动读音，让孩子凭第一眼判断。
  • 认识就点绿色「认识」（键盘 ← 或 1，或鼠标 左键点字卡）；不认识就点红色「不认识」（键盘 → 或 2，或鼠标 右键点字卡）。
  • 点错了不用退出：按 ↑ 回到上一个字回看，按 ↓ 往后，按 End 直接回到继续过字的位置。回看时按钮会显示原来的标记，点另一个即可改过来。
  • 回看时颜色一眼就能分辨：还没标的字是黑色，标了「认识」的字是绿色，标了「不认识」的字是红色。
  • 也可以点字卡下方的「↑ 回看上一个」；回看时会多出「往前看 / 往后看 / 回到继续过字」按钮。
  • 不需要一次过完。点左上角 × 可以退出，下次从停下的地方继续。
  • 过完会显示「认识多少 / 不认识多少」，然后就可以开始每天复习。

自评标错了怎么办

  • 认字页顶部点「自评标错了？改几个字」。
  • 可以搜汉字、拼音（不用打声调，例如输入 kuai 也能搜到「块」）或组词。
  • 找到字后点「改成认识 / 不认识」。还没复习过的字会按新自评重排复习时间；已经复习过的字只改标签，不改下次复习时间。
  • 按 Esc 或点「返回认字」回到认字页。

每天：按记忆曲线复习

  • 今日页会显示「今天有 N 个字要复习」。点「开始复习」进入。
  • 自评「不认识」的字：先看一张完整字卡，再答一道题。
  • 自评「认识」的字：直接答题验证，不先看字卡。
  • 答对会升级，下次间隔变长；答错会降级，下次更早出现。
  • 每组最多复习 15 个字。没排进这一组的，下次优先。
  • 间隔是 1 / 2 / 4 / 7 / 15 / 30 / 60 天。即使到了最高一级，也还会滚动复习。

打印不会的字

  • 认字页顶部有「打印不会的字 · N 个」；自评「不认识」的字都会进清单，也可以勾选「包含高估字」。
  • 打印预览会显示大字、拼音和组词，拼音和组词的字号更大；不显示课文来源，A4 纸每页约 20 个字，右上角有小方框，孩子会了就打勾。
  • 默认显示拼音和组词。如果只想练纯认字，可以同时取消「显示拼音」和「显示组词」。
  • 点「打印」调用系统打印窗口；也可以先在预览里检查，再按 Esc 返回认字页。

为什么要分「自评」和「实测」

孩子说「认识」，不一定真的读得出来。应用会把两种情况分开记：

  • 高估字：自评认识，但第一次答题错了。家长页会单独列出来，优先复习。
  • 低估字：自评不认识，但第一次答题对了。会自动跳一级，避免重复太多次。
  • 自评不会直接增加课内的「学过 / 688」，也不等于已经掌握；答题验证后才升级。
  • 「幼儿识字 1300」是独立范围，不进入课内今日任务，也不改变课内 688 字的统计。
建议：第一次可以直接过「幼儿识字 1300」，一次过不完就分几次；过完后打印不会的字， 每天复习一组，再配合课内今日任务。过字时不要催，孩子犹豫超过两三秒就点「不认识」， 交给后面的复习去解决。

11家长看板

每周看一次就够了，不用天天盯。

四个数字

  • 学过 / 688：已经学过的不同汉字数。
  • 已掌握：复习到最高一级、间隔最长的字。
  • 今日正确率：今天答题的正确比例。
  • 连续学习天数：连续有答题的天数。

最近 7 天

柱状图显示每天的答题量，下面汇总学习天数、分钟数、新字数和正确率，并给一句学习建议。 柱子上悬停可以看到当天答了多少次、学了多少新字。

部首徽章

统计学过的字里出现最多的部首。同一个部首集满 5 个字是银章，10 个字是金章。 可以用来做小目标，比如「今天再找两个三点水的字」。

易错字

列出答错过、或者正确率低于 80% 的字，最多 10 个，按错误次数排序。 点一行可以直接打开这个字的字卡。建议第二天开始学习前，先点开读一遍。

艾宾浩斯认字

显示已自评、自评认识 / 不认识、已答题验证、高估字、今天待复习。自评只是分桶， 答对才会升级。下面会单独列出「高估字」和「低估字」，可以点字打开字卡。

学习设置

设置说明建议
每天新字 1–10 个，默认 5 个。按整课安排，可能多 1–2 个。 3–6 个。先稳住复习，再慢慢加。
声音 关闭后所有读音和提示音都静音。 睡前或公共场合可以关。
自动播放读音 点开新字卡时自动连读字音和组词。 刚开始建议开着；孩子会自己读后可关掉。
减少动效 关闭页面动画和过渡。 孩子容易分心、或说「晃眼睛」时打开。

数据

  • 导出答题 CSV：每次答题的明细，可以用表格软件打开。
  • 备份学习记录：下载 hanzi-stats-日期-时间.db，包含所有进度。
  • 备份字库：下载 hanzi-content-日期-时间.db，一般不需要。
  • 清空进度：会删除所有答题记录、普通进度和艾宾浩斯认字记录，不能撤销。清空前先备份。
「清空进度」是给重新开始用的。 如果只是想换个每天新字数量，不用清空，直接调上面的滑块就好。

12键盘操作（可选）

孩子学会用键盘后，可以少用鼠标。

按键作用
↑ ↓ ← →在选项之间移动高亮。刚进题目时没有高亮，按方向键才出现。
Enter确认选中的选项；答完后进入下一个；学字卡时开始认字；结算页再学一组。
Esc关闭字卡弹窗；护眼提醒时跳过；退出整体过字；从打印预览或改自评页返回认字页。
Enter（弹窗里）关闭弹窗。
← / 1整体过字时点「认识」；鼠标左键点字卡也可以。
→ / 2整体过字时点「不认识」；鼠标右键点字卡也可以。
↑整体过字时回看上一个字，可以重新标记「认识 / 不认识」。
↓回看时往后翻一个字；翻到最新就回到继续过字。
End从回看状态直接回到继续过字的位置。

没选中任何选项时按 Enter 不会答题，这是故意的，避免误触。

13陪学建议

比「学了多少」更重要的是「明天还想来」。

  1. 固定时间，短而稳。每天 10–12 分钟，比周末一次学一小时有效。
  2. 先复习，再新字。应用已经排好了顺序，不要跳过复习直接学新的。
  3. 让孩子自己点。家长负责读题、鼓励、提醒休息，不负责替点。
  4. 错字不批评。答错会安排复习，第二天在「易错字」里再看一遍就好。
  5. 把「读一读」当奖励。学完字读一篇短文，比多做十道题更有成就感。
  6. 每周只看一次家长看板。重点看「易错字」和「连续天数」，不用盯正确率。
  7. 不要为了赶进度调高每天新字。3–6 个足够，复习跟不上会越学越累。
  8. 保护眼睛。12 分钟提醒不是摆设，弹出时真的让孩子看远处数 20 下。
  9. 以学校课本为准。应用是课后补充，不替代课堂；老师要求的进度和读音优先。
一句话版本：每天 10 分钟，先复习再新字，让孩子自己点，错了明天再来。

14常见问题

遇到问题先看这里，大部分都能自己解决。

Q双击 start.command 没反应，或者提示「无法打开」

在 start.command 上右键 → 打开，再点「打开」。如果还是不行，到「系统设置 → 隐私与安全性」里点「仍要打开」。另外确认电脑里有 Python 3，可以在终端输入 python3 --version 检查。

Q浏览器没有自动打开

手动在浏览器输入 http://127.0.0.1:8765。如果端口被占用，应用会自动换到 8766–8775，以终端窗口里显示的地址为准。

Q没有声音

先看右上角是不是「静」，点一下切成「声」；再检查 Mac 音量和静音键；然后到「今日页 → 家长看板 → 学习设置」确认「声音」和「自动播放读音」是开着的。单字和拼音用的是内置 mp3，词语和句子用的是系统语音，音色不同是正常的。用蓝牙耳机时确认已经连上。

Q学习记录会丢吗？

记录保存在本机的 data/stats.db，正常关机、重启都不会丢。只有点「清空进度」才会删除。建议每月在家长页点一次「备份学习记录」。

Q换电脑或重装系统，怎么把进度带走？

先在旧电脑的家长页点「备份学习记录」，得到 hanzi-stats-日期-时间.db。在新电脑上先双击 stop.command 停止应用，把这个文件改名为 stats.db，放到 data/ 文件夹里覆盖原文件；如果旁边有 stats.db-wal、stats.db-shm，一起删掉。再双击 start.command 即可。

Q两台电脑能同步进度吗？

不能自动同步，数据在各自电脑上。可以用上面的备份方法手动迁移，但不要两台同时学，否则后覆盖的会盖掉另一台的新记录。

Q为什么第一课有 6 个字，我设置的是 5 个？

新字是按整课安排的，避免把一课拆成两天。课文边界允许比设置多 1–2 个字，第一课《天地人》就是 6 个字一次学完。

Q为什么有的字没有「字族」或「多音字」？

字族需要有同部件或同部首的字；独体字、或者这个部首在 688 字里只出现一次，就没有可归类的兄弟字。多音字只收教材标注的 8 个和音频齐全的 30 个常见字，缺音频的不会放进来，避免点了没声音。

Q字的读音和课本不一样

以课本为准。拼音和解释是人工整理的，可能有出入；如果发现明显错误，记下是哪个字、哪一课，反馈给维护者修正。

Q「艾宾浩斯认字」和「今天的任务」有什么区别？

「今天的任务」按课本顺序学新字，用的是普通间隔复习；「认字」先让孩子自己过一遍幼儿识字 1300（也可以只过课内 688 / 上册 / 下册），只复习孩子自评过的字，并按 1/2/4/7/15/30/60 天安排。两套记录分开，互不覆盖。时间紧时先做当天到期的认字复习，再学新字。

Q孩子答错很多，要不要当天重学？

不用。答错会让这个字降一级，按新的等级安排复习，越不熟出现得越早；家长页也会把它列进「易错字」。当天反复罚做容易让孩子反感，第二天开始前点开读一遍更有效。

Q能不能学写字、笔顺？

这个应用只做认读：见字能读、听音能选、在词句里能认。不做描红、笔顺和书写评分，避免和学校教学冲突。

Q能在 iPad 或手机上用吗？

目前主要给这台 Mac 的浏览器使用，服务只在本机开放，同一 Wi-Fi 下的其他设备默认访问不到。手机端样式已经适配，但需要额外配置才能访问，暂不推荐作为日常用法。

Q清空进度后还能恢复吗？

不能撤销。如果之前备份过 hanzi-stats-日期-时间.db，可以按「换电脑」的方法恢复；没有备份就恢复不了。

Q需要联网吗？会上传孩子的数据吗？

只有第一次安装依赖需要联网，之后完全离线。应用不登录、不上传，所有记录都在这台电脑的 data/ 文件夹里。

Q应用关不掉，或者提示端口被占用

双击 stop.command，它只会停止本项目。如果还不行，重启电脑最省事。不要同时双击两次 start.command，第二次只会打开已经运行的页面。
