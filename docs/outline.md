# 汉字小岛 · 内容与关卡规划

## 一、定位

- 对象：一年级（6–7 岁），以 2024 统编版教材为顺序。
- 目标：认读。见字能读、听音能选、在词句里能认。
- 不做：描红、笔顺、写字评分。
- 时长：每天 10–12 分钟，4–6 个新字 + 到期复习。
- 形态：macOS 本地服务 + 浏览器，SQLite 记录进度，离线可用。

## 三、每天怎么学

| 环节 | 时长 | 内容 |
|---|---|---|
| 复习 | 2–3 分钟 | 到期字，混合题型 |
| 学新字 | 4–5 分钟 | 4–6 个新字，每个一张学字卡 |
| 认字游戏 | 2 分钟 | 听音选字 / 组词 / 填空 / 拼音 |
| 结算 | 0.5 分钟 | 星星、正确率、明天复习预告 |

新字第一次按「听音 → 组词 → 填空 → 拼音」轮换，避免只做一种题。复习也轮换。

## 四、学字卡字段

每个字包含：

- 大字、拼音、部首、笔画、结构、造字法
- 儿童化意思
- 2–3 个组词
- 1 个生活例句（尽量用已学字）
- 记忆口诀（明确是口诀，不冒充字源）
- 2–3 个形近字
- 可出的题型

## 五、掌握与复习

- Leitner 盒子 0–5，间隔 1/3/7/15/60 天。
- 答对升一级，答错降一级（最低 0）。
- 已认识：见过、答过；已掌握：box 5。
- 家长看板按「错得最多、正确率最低」列易错字。
- 复习优先于新字；每天新字上限可调 1–10，建议 3–6。

## 六、内容原则

1. 教材顺序优先，字频只用于补字和复习排序。
2. 多音字只教当前课文语境的一个读音。
3. 例句要自然，不为了塞字造病句；如果例句里没有目标字，就不出填空题。
4. 形近字优先从当前字表里选；没有合适字时可用常见字。
5. 口诀只帮助记忆，不写成“字源考证”。
6. 每个字的内容先写 30 个一批，校验后再扩。

## 七、后续阶段

- M2：补到 120 字；每 20–30 字配一篇 2–4 句小短文。
- M3：预生成单字音频；米纸视觉打磨；手机/平板 QA。
- M4：补一上 280、一下 410；增加总复习和字族（青→清晴情请睛）。
- 之后：完整操作流水、家长周报、打印字卡、打包 `.app`。
