# data/curriculum — 课程位置数据（P0 数据底座）

按 `docs/specs/2026-11-12-p0-content-foundation.md` 第五节的格式，把 2024/2025 新版统编教材识字表
录入为「书 → 单元 → 课文 → 字位置」。原始录入文件在 `data/sources/`。

## 文件

| 文件 | 内容 | 行数 | 不同字 | 来源 |
|---|---|---|---|---|
| `1a.csv` | 一年级上册（2024 秋 统编版）识字表 | 283 | 279 | 见下 |
| `1b.csv` | 一年级下册（2025 春 统编版）识字表 | 419 | 413 | 官方电子课本第 114–116 页 |

- `1a` 283 行是「字次」：多音字在不同课重复列出（如 数/着/长），不同字 279 个。
  教材标注为 280 字：按课文表与「三字句识字表」两个来源比对，交集 277、
  按课文表独有「旁旦」、三字句独有「元星期」，**需对照课本识字表核实这 5 个字**。
- `1b` 419 行字次 / 413 不同字；课本标注 410 = 扣除 9 个蓝色多音字
  （得、背、只、乐、了、结、呀、空、哪——此前已认读，此处作多音字，不计生字总数）。

## CSV 列

```
book_id,unit_no,unit_title,unit_kind,lesson_no,lesson_title,lesson_kind,lesson_order,item_order,
char,pinyin_override,audio_key_override,meaning_override,words_override,sentence_override,mnemonic_override
```

- `override` 列留空时用 `data/characters.csv` 的默认内容。
- **`pinyin_override` / `audio_key_override` 规则**：同一本书里同一字出现多个读音的字
  （1a：数、着、长；1b：乐、哪、结），以及 1b 的 15 个蓝色多音字位置，逐位置填写，
  保证按课文语境发音。
- `lesson_kind`：1a 由课文标题前缀（识字/汉语拼音/阅读/语文园地）判断；
  1b 用官方课本的板块（识字/阅读）判断。

## 单元划分（按 2024/2025 目录）

- **1a（38 课 → 8 单元）**：第一单元 识字（课1–5）｜第二~四单元 汉语拼音
  （课6–8 / 9–14 / 15–20）｜第五单元 阅读（21–25）｜第六单元 识字（26–30）｜
  第七、八单元 阅读（31–34 / 35–38）。
  每单元字次：33 / 14 / 26 / 30 / 51 / 51 / 36 / 42 = 283。
- **1b（36 课 → 8 单元）**：第一单元 识字（1–5）｜第二~四单元 阅读（6–9 / 10–13 / 14–17）｜
  第五单元 识字（18–22）｜第六~八单元 阅读（23–27 / 28–32 / 33–36）。
  每单元字次：55 / 46 / 48 / 43 / 60 / 59 / 60 / 48 = 419。
